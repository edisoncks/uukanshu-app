1.2.28 候選版本 rc.2（供測試）

- 更新檢查失敗時，對話框多了「改用瀏覽器下載」可按
- 「跳過此版本」要等設定真的寫入才收起提示；寫入失敗會直接告訴你
- 更新說明不再被截斷，完整內容可在對話框內捲動閱讀
- 修正章節內文的引號等特殊字元顯示成亂碼的問題
- 修正章節列表在同尺寸變動時，整本下載顯示完成但其實漏抓一章的問題
- 「有更新」小紅點只在整本確實下載完成後才清除
- 搜尋時立即取消上一次查詢，不會再出現舊結果蓋在新輸入上

與 rc.1 的使用者可見行為相同；此版另外清除了建置警告（書架圖示改用自動鏡像版本，在由右至左的語系下才會看出差異）。

這是 1.2.28 的測試候選版，正式版推出後可在 App 內直接更新。
